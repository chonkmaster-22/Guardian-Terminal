GUARDIAN TERMINAL
A mod manager for Savage Wind, the Breath of the Wild PC port.
Made by chonkmaster-22 - https://github.com/chonkmaster-22/guardian-terminal

QUICK START
1. Keep this folder somewhere you can write to (for example C:\Games\Guardian Terminal),
   not in Program Files: your mods, profiles and save backups are kept in it.
2. Run GuardianTerminal.exe.
   Windows may say "Windows protected your PC" the first time, because the program isn't
   code-signed: click "More info", then "Run anyway".
3. The welcome screen walks you through it:
   - Savage Wind: Guardian Terminal finds it, or installs the newest release from
     Savage Wind's own GitHub page (Settings > Savage Wind > Install or update).
     Savage Wind's setup asks for YOUR OWN game files (Breath of the Wild 1.9.0).
   - Add mods: the GameBanana page, or drop a mod's .zip / .7z / .rar / .bnp on the window.
     Breath of the Wild SWITCH mods work (the ones with a "romfs" folder).
   - Press Play.

To unpack .7z and .rar mods, install 7-Zip (free): https://www.7-zip.org
