**Guardian Terminal** is a mod manager for [Savage Wind](https://github.com/Revivedx/SavageWindRecomp), the Breath
of the Wild PC port: install Switch mods, let it merge them, press Play.

### Download

**`GuardianTerminal-vX.Y.Z-win-x64.zip`** below: extract it to a folder you can write to (not Program Files) and
run `GuardianTerminal.exe`. Windows may say "Windows protected your PC" because the program isn't code-signed:
**More info ▸ Run anyway**. The `.sha256` file is the zip's checksum.

You need Savage Wind set up with your own copy of the game (1.9.0). Guardian Terminal can install Savage Wind for
you; it never includes or downloads game files.
