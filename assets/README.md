# assets

- `emblem.png` (when it's here): Guardian Terminal's emblem, black and white. `build.ps1` builds it into the exe
  (the window's emblem) and makes the app icon from it (`tools\MakeIcon.cs`). Without it, the drawn Guardian of
  `src\UI\Emblem.cs` is used.

Only put art here that you're allowed to publish.
